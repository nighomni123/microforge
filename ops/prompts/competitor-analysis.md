# Prompt: Competitor Review Analysis

Mine competitor reviews (1–3 stars) from Play Store / App Store / Chrome Web Store /
G2 etc., paste 20–40 verbatim reviews, then run:

```text
Below are user reviews of competing [TOOL TYPE] apps/products.

1. Cluster the complaints into themes and rank by frequency.
2. For the top theme, state the unmet need in one sentence.
3. Propose a simpler product concept that solves that need WITHOUT the failure mode
   the reviews mention (e.g., no login, no ads-over-content, no paywalled basics).
4. List the riskiest assumption in that concept and a 1-hour way to test it.
5. Draft 3 FAQ questions my version should answer that clearly signal the difference.

Rules: do not suggest copying features for features' sake; simpler beats more;
never recommend dark patterns (forced registration, fake urgency, hidden cancel).

REVIEWS:
[PASTE REVIEWS]
```
